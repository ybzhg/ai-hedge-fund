How yahoo-study turns daily prices into a paper portfolio, and how starter uses Financial Datasets for fundamentals and earnings.

Overview

Both funds run in aihf and start with $100,000 in simulated capital. They share the market-session clock, portfolio construction, simulated broker, and ledger. The mandate determines what each strategy reads and how it produces a signal.

Software architecture

The paper session engine is shared by both funds. The mandate selects the strategies and their requirements, which determine the data provider and whether the run needs a model API.

Where the funds differ. yahoo-study uses Yahoo daily prices for its momentum rule. starter adds Financial Datasets fundamentals and earnings history, with a separate LLM provider for the value agents. Both paths use the same portfolio, risk, paper broker, and ledger components.

Key features

  • Daily prices. Yahoo returns open, high, low, close and volume. The adapter requests an exclusive API end date, filters to the requested inclusive window and caches the resulting bars separately from Financial Datasets.
  • Deterministic momentum. The study uses close prices and requires at least 11 usable bars. Positive scores qualify for a long position, weighted in proportion to conviction. Zero or negative scores carry zero weight, and the model abstains when history is too short.
  • Risk and execution timing. The study caps each position at 25% and retains the unallocated balance as cash. A decision is eligible for simulated execution in the following completed session. The first run establishes a decision with no pending orders to fill.
  • Paper controls and audit trail. Run one session, start the runner, halt a fund, or review the session history. The hash-chained ledger records signals, raw and final weights, fills, holdings and NAV.

Financial Datasets sequence

This is the code path for running starter. The market-data client uses a Financial Datasets API key or the supported x402 payment path. The value agents also use the configured model provider when a prompt has no cached result. PEAD, or post-earnings announcement drift, uses earnings history to build a quantitative signal.

This sequence describes the implementation for a rebalance. The report’s recorded result is from yahoo-study. Daily sessions between rebalances can mark the portfolio without issuing a new assessment.
